Our treasures

Data Infrastructure

This module is responsible for connecting to brokers and exchanges, collecting and standardizing market data.
It integrates API connectors, a PostgreSQL storage system, and the QAnt Lib library, ensuring reliable and unified operation of all platform components.
Includes: the connection core, the QAnt Lib library, and API modules for various platforms.

Research & Testing Environment

A tool for analyzing and testing custom algorithms in a secure environment.
Allows you to model scenarios, test the stability of parameters, and evaluate the effectiveness of logic on historical data.
Includes: a library of demo algorithms, research modules, and visualization tools.

Execution Core

The central part of the platform, enabling the execution of custom algorithms and interaction with the data infrastructure.
Processes signals, manages processes, and monitors the system state in real time.
Includes: process managers, a signal routing system, and a load balancing module.

Monitoring & Interface

Visual control and notification module.
Allows you to monitor system status, analyze logs, and receive event notifications via the interface or a Telegram bot.
Includes: QAnt Terminal, logging system, and notification module.
